03 /发车顺序与执行要点

以开幕时间T倒排，远端先发、近场提前循环，避免集中抵达。

FIRST / 优先发车

星沙北部与市中心先走

碧桂园凤悦凤凰、三景韦尔斯利、明城国际、星沙希尔顿欢朋，以及潇湘华天、融通长城、长沙华天、通程国际，建议在T前100—115分钟离店。

DIRECT / 满载直达

不让满车沿途接站

每家酒店独立编车、按名单上车。只有未坐满的尾车考虑与顺路酒店拼接，并提前保留座位。远端去程按一次送达安排，暂不依赖车辆返回补接。

SHUTTLE / 近场循环

1,373人也要提前启动

近场需要30车次。可研究15辆车各跑2趟，提供1,440个客位；须先验证装客、行驶、下客、返回的完整周转时间。T前90分钟启动，争取T前40分钟送完。

运力解释：198车次是各酒店分别取整后的基准，不含备用车。若远端168辆车一次送达、近场15辆循环，则为183辆的待验证配置。不能将30个短驳车次直接当作30辆必租车辆，也不能未经周转核验就压缩车辆数。

计算口径与待确认事项

单间 / 大床房 / 套房按1人，标间 / 双床房 / 双间按2人，亲子房按3人。每家酒店人数＝向上取整（满住人数×80%）；车次＝向上取整（酒店预估人数÷48）。暂按全部预估住客参加开幕式。大床房按1人是会议住宿假设，并非酒店法定最大入住人数。

查看算例与调度前检查项

施柏阁大观：330间房，满住470人，470×80%＝376人，376÷48向上取整＝8车次。各酒店分别取整后，合计8,923人。

发车前须确认：开幕日期及时间、各酒店实际名单、套房与亲子房入住口径、车辆核定客位、会议中心接待容量、下客入口与候停区。各酒店上车集合时间建议比本车发车早15分钟；车队分小批次离店，场馆按预约窗口接车。
